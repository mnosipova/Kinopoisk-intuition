# Угадай рейтинг — Киноинтуиция

Мобильная веб-игра по мотивам датасета сериалов Кинопоиска. Угадывай рейтинги сериалов бегунком и набирай до 10 000 баллов за 10 раундов.

## Структура проекта

```
ugadai-reiting/
├── index.html   — единственная страница приложения
├── style.css    — стили (тёмная тема + оранжевый Кинопоиска)
├── app.js       — игровая логика (раунды, баллы, статистика)
├── data.js      — данные 50 сериалов из датасета (обложки 400x600)
└── README.md
```

Никаких зависимостей, сборки и сервера не требуется — чистые HTML/CSS/JS.

## Публикация на GitHub Pages

1. Создай репозиторий на GitHub, например `guess-the-rating`.
2. Загрузи в корень репозитория все 4 файла: `index.html`, `style.css`, `app.js`, `data.js` (и этот README).
3. В настройках репозитория: **Settings → Pages → Source → Deploy from a branch → `main` / `(root)` → Save**.
4. Через минуту игра будет доступна по адресу `https://<username>.github.io/guess-the-rating/`.

Локальный просмотр: просто открой `index.html` в браузере (данные и картинки подгружаются напрямую с CDN Кинопоиска).

## Правила игры

- 10 раундов, в каждом — случайный сериал из датасета (без повторов).
- Диапазон угадывания: 7.0–10.0 с шагом 0.1. Рейтинг скрыт до нажатия «УГАДАТЬ».
- Баллы: 1000 − 100 × (ошибка в десятых). Ошибка 0.3 → 700 баллов, 1.0 и больше → 0.
- В конце: средняя ошибка, переоценки/недооценки, лучший и худший ответ, тип игрока (Кинокритик / Оптимист / Скептик) и процент киноинтуиции.
